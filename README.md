# Hoosier Bloom Coffee & Pastry

Complete standalone website exported from the Sites version. No build step, dependencies, API keys, or Sites account required to run this code.

## Files
- index.html: page content, links, and favicon
- style.css: responsive styles and subtle animation
- coffee.jpg: generated illustrative coffee and pastry photograph
- .nojekyll: disables Jekyll processing on GitHub Pages

## Preview locally
Extract the ZIP and open index.html in your browser. Keep style.css and coffee.jpg beside it.

## Upload to GitHub
1. Create a repository named hoosier-bloom (or choose your own name).
2. Extract this ZIP. Upload its contents into the repository root, with index.html at the top level, not inside an extra folder. Commit the files.
3. If you want to publish through GitHub Pages, open repository Settings > Pages.
4. Select Deploy from a branch, select main and / (root), and Save.
5. GitHub will display the website address after deployment finishes. Repository visibility and plan determine Pages availability; choosing a public repository makes the source publicly readable.

Official setup guide:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Editing
Edit index.html for business information and links. Edit style.css for colors, typography, spacing, and responsive layouts. Replace coffee.jpg with an actual business photograph using the same filename, then update the alt text and remove the illustrative-photography footer label when appropriate.

The menu and hours link to Facebook rather than displaying unverified prices or schedules. The photograph is AI-generated illustrative imagery, not a photograph of the actual business or its products.
