# Hoosier Bloom Coffee & Pastry

Standalone, responsive café website. No build step, dependencies, API keys, or Sites account is required for the exported website.

## Preview and edit
Open dist/index.html locally. Edit that file for page content and menu prices, dist/style.css for the visual system, and dist/animations.js for menu/scroll interactions and dist/intro.js for the opening sequence. The downloadable GitHub ZIP puts these files at its root, so use index.html instead of dist/index.html there.

## GitHub Pages
Upload the ZIP contents (not the ZIP itself) into the repository root. In Settings > Pages, select Deploy from a branch, main, and / (root), then save. Publishing depends on the repository's visibility and GitHub plan. A public repository exposes its source publicly.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Features
- Full-screen Hoosier Bloom opening on every refresh, with a 2.3-second title hold and 0.9-second curtain reveal. Skip button, Escape key, reduced-motion bypass, and timed recovery included.
- Hero animations start after the opening, followed by stronger photo and section reveals.
- Menu categories with keyboard-operable tabs; all categories remain readable without JavaScript.
- Selected DoorDash listing prices, with an in-store/option-price distinction.
- Seasonal drink feature, botanical illustration, and owners' story.
- Actual café and family photographs with attribution.
- One visible Facebook link and an existing DoorDash ordering destination.
- Mobile Menu / Directions / Call bar.
- Reduced-motion support, semantic headings, and local-business structured data.
